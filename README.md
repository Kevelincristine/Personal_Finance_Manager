  🇺🇸 # 💰 Personal Finance Manager

A lightweight and responsive **personal finance management web application**, designed to help users easily track income and expenses.  
This project demonstrates how a simple front-end solution can deliver **real value**, usability, and clean technical implementation.

---

## 📌 Project Overview

**Personal Finance Manager** allows users to manage their finances in a clear and intuitive way, without the need for accounts, servers, or complex setup.

The application runs entirely in the browser and stores data locally, making it:
- Fast
- Secure (data stays on the user’s device)
- Easy to use

This project was developed as a **portfolio and client-oriented example**, showcasing practical front-end development skills.

---

## 🎯 Key Features

- Set an initial balance
- Add income and expense transactions
- Categorize transactions (Food, Study, Leisure, etc.)
- Automatic balance calculation
- View transaction history
- Filter transactions by date
- Persistent data storage using LocalStorage
- Fully responsive layout (Mobile First)

---

## 🧠 Technical Highlights

- Built with **Vanilla JavaScript** (no frameworks)
- Clean DOM manipulation and event handling
- Local data persistence using **LocalStorage**
- Modular and readable logic
- Responsive UI using modern **CSS (Flexbox & variables)**
- Simple animations for better user experience

---

## 🧑‍💼 Value for Clients

This project shows how a custom web application can:

- Replace spreadsheets for simple financial tracking
- Be customized for different business needs
- Deliver a smooth experience on mobile and desktop devices

Ideal for:
- Personal finance tools
- Small business expense tracking
- Educational projects
- MVPs and prototypes

---

## 📱 Responsive Design

The interface was designed using a **Mobile First** approach and adapts seamlessly to:

- Smartphones
- Tablets
- Desktop screens

 🇧🇷 # 💰 Gerenciador de Finanças Pessoais

Uma aplicação web **leve, responsiva e intuitiva** para gerenciamento de finanças pessoais, desenvolvida para ajudar usuários a acompanhar entradas e saídas de forma simples e eficiente.  
Este projeto demonstra como uma solução front-end pode gerar **valor real**, boa usabilidade e uma implementação técnica bem estruturada.

---

## 📌 Visão Geral do Projeto

O **Gerenciador de Finanças Pessoais** permite que o usuário organize sua vida financeira de maneira clara, sem necessidade de contas, servidores ou configurações complexas.

A aplicação funciona totalmente no navegador e armazena os dados localmente, o que garante:
- Rapidez
- Privacidade (os dados permanecem no dispositivo do usuário)
- Facilidade de uso

Este projeto foi desenvolvido como um **exemplo para portfólio e apresentação a clientes**, destacando habilidades práticas em desenvolvimento front-end.

---

## 🎯 Funcionalidades Principais

- Definição de saldo inicial
- Registro de entradas e saídas financeiras
- Classificação de transações por categoria (Alimentação, Estudos, Lazer, etc.)
- Cálculo automático do saldo
- Visualização do histórico de transações
- Filtro de transações por data
- Persistência de dados usando LocalStorage
- Layout totalmente responsivo (Mobile First)

---

## 🧠 Destaques Técnicos

- Desenvolvido com **JavaScript puro (Vanilla JS)**
- Manipulação clara e eficiente do DOM e eventos
- Armazenamento local com **LocalStorage**
- Lógica organizada e de fácil manutenção
- Interface responsiva usando **CSS moderno (Flexbox e variáveis)**
- Animações sutis para melhorar a experiência do usuário

---

## 🧑‍💼 Valor para Clientes

Este projeto demonstra como uma aplicação web personalizada pode:

- Substituir planilhas em controles financeiros simples
- Ser facilmente adaptada para diferentes tipos de negócio
- Oferecer uma experiência fluida em dispositivos móveis e desktops

Ideal para:
- Controle financeiro pessoal
- Gestão de despesas de pequenos negócios
- Projetos educacionais
- MVPs e protótipos

---

## 📱 Design Responsivo

A interface foi projetada seguindo a abordagem **Mobile First** e se adapta perfeitamente a:

- Smartphones
- Tablets
- Computadores
